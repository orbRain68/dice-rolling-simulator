# Dice Rolling Simulator

A Tkinter desktop app that rolls a six-sided die and shows the matching face in the center of the canvas.

## Run

Install Pillow, then start the app:

```
pip install pillow
py Game.py
```

Click **Roll** to get a random number from 1 to 6 and display that die.

## Files

- `Game.py` — game window, roll button, and dice display
- `images/dice1.png` through `images/dice6.png` — faces for each roll
- `images/stars.jpg` — canvas background
- `images/Untitled.png` — roll button image
